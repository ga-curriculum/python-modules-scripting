## About
Discover how to import and use libraries to enhance their programs. Also learn how to read documentation of new libraries.  And learn how to write Python scripts.

## Learning Objectives

*You will be able to:*

- Understand how libraries, packages, and modules relate to one another.
- Use import statements to access Python libraries.
- Use Python scripts to automate tasks.
- Create Python scripts to read and write to files.
